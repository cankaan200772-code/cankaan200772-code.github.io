Kurulum (Detaylı anlatım)

  1. Java kur: GTNH genelde Java 8, 11, 25 ile çalışır. (Biz size java 25 i öneririz daha iyi bir performans ve daha güncel kalmanız için.)

  2. Modpack yöneticisi: Genel kurulum Prisim launcher üzerinden yapılır.

  3. Javanı yükle: ADOPTIUM üzerinden javanı kur.

  4. Javanı launchera ekle: Ayarlardan javanı seç.

  5. Java Kurulumunu Tamamla sitemizde indirme notları kısmına giderek java kurulumununuzu tamamlayınız.

  6. İleri ayarlar: JVM argümanları ve RAM için (ör. -Xmx6G) ayarlama yap.
Oynanılan Platform: Prisim launcher
Önerilen RAM: 6GB+
Java: 8/11/25

Hangi Java sürümünü kullanmalıyım?
GTNH sürümüne göre değişir; çoğu zaman Java 8 veya 11 önerilirsede java 25 kurmanızı şiddetle öneririz. Pack notlarını kontrol et.
Performans için ne önerirsin?
En düşük Win10 işletim sistemi kullanmanız, RAM 6GB+, Ekran Kartı: En az 6 GB VRAM’e sahip orta seviye bir kart önerilir. Örnek kartlar: RTX 3060 serisi, RX 580/8GB gibi.
